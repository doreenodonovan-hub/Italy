# Italy Choice Lab

Italy Choice Lab is an interactive travel-discovery prototype for choosing Italian regions and experiences before building an itinerary.

**Live site:** https://doreenodonovan-hub.github.io/Italy/

Current published version: **v11**

The site helps travelers:
- identify the travel experiences that matter most to them
- compare regional matches
- save multiple regions and activities
- discover Wildcards and Hidden Gems
- consider how far they are willing to travel from a base
- review saved ideas on a map
- see one efficient order for saved regions and a warning when too many regions may crowd a short trip

The current website is published from the `main` branch with GitHub Pages.
